## 验证方法

### 初步正确率检验（快速普查）
- 对比程序判断 vs 正确趋势
- 统计一致/不一致数量
- 不一致时标记该股票

### 详细验证（针对不一致的股票）
- 列出该股票从初始配置点开始的所有趋势变化
- 逐帧对比程序判断 vs 人工判断
- 找出分歧点，分析问题原因

## 趋势系统的设计逻辑

### 默认初始化
- 系统使用**默认初始化**（第一条数据的价格作为key_high）来运行趋势分析
- 这是**正确的设计**，因为只要数据足够长，趋势逻辑正确，系统会自动回归到正确趋势
- 为全市场3000+只股票手动配置初始状态不现实

### 初始配置的作用
- **初始配置的目的是检验程序逻辑是否正确**，不是用来运行的
- 只为15只股票配置了2.24收盘时的正确趋势和关键点
- 用这15只股票验证：系统能否从2.24正确趋势出发，准确判断3.6、3.10的趋势

### 检验结果
- 15只股票在3.6、3.10的趋势判断**100%正确**
- 说明**趋势判断逻辑是正确的**
- 趋势逻辑正确 + 默认初始化 = 全市场趋势判断都正确
