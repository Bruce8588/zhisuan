# 趋势判断逻辑检查流程

## 目的

验证趋势判断程序的正确性，确保程序能够准确判断任意时刻的趋势。

## 检查方法：三重检验

通过对比三个时间点的趋势来判断程序逻辑是否正确。

| 时间点 | 说明 | 作用 |
|--------|------|------|
| 2.24初始配置 | 程序使用的起点配置 | 验证初始状态是否正确 |
| 3.6正确趋势 | 人工判断当天收盘趋势 | 验证趋势演变是否正确 |
| 3.10正确趋势 | 人工判断当天收盘趋势 | 验证趋势演变是否正确 |

## 检查步骤

### 第一步：定位检查股票的数据

1. 在全市场数据中定位15只检查股票
2. 检查数据完整性（是否包含2.24、3.6、3.10三个时间点）

### 第二步：对比程序判断与正确趋势

1. 读取股票的趋势判断文件
2. 获取三个时间点的收盘趋势
3. 与"正确趋势"进行对比
4. 统计一致/不一致数量

## 预期结果

- 趋势判断逻辑正确时，程序应能完整还原人工判断的趋势演变过程
- 如果初始配置正确，三个时间点的趋势应与"正确趋势"完全一致
- 初始配置错误会导致趋势演变偏离正确路径

## 注意事项

1. **初始配置是关键** - 必须使用正确的初始配置才能准确判断后续趋势
2. **数据完整性** - 趋势判断文件必须包含三个检查时间点
3. **收盘趋势** - 取当天最后一条记录的趋势作为收盘趋势
